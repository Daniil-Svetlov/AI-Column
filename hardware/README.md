# Железо AI-Column

| Файл | Что это |
|---|---|
| `schematic.svg` | полная схема соединений: все провода, питание, АКБ, таблица GPIO |
| `BOM.csv` | список компонентов со ссылками (разделитель `;`, открывается в Excel) |
| `tools/schematic_gen.py` | генератор схемы; `python3 tools/schematic_gen.py` — перерисовать и проверить пересечения проводов |

Распиновка, питание, аккумулятор и порядок сборки — в [../docs/HARDWARE.md](../docs/HARDWARE.md).
