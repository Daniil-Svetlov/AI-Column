# AI-Column — умная колонка с несколькими ИИ-агентами

Самодельная голосовая колонка на **ESP32-S3**. Нажимаешь кнопку (или касаешься экрана) и говоришь. Колонка передаёт звук на твой сервер, там речь распознаётся, вопрос уходит подходящему агенту — **Claude**, локальному **Qwen**, **Kimi** или любой другой модели. Ответ озвучивается и стримится обратно по предложениям: колонка начинает говорить, пока модель ещё пишет.

```
 ┌──────────── колонка (ESP32-S3) ────────────┐         ┌──────────────── сервер (Node.js) ────────────────┐
 │ 2× INMP441 ─I2S─┐                          │  Wi-Fi  │  речь → текст (Whisper)                          │
 │                 ├─ ESP32-S3 ── WebSocket ──┼────────►│     → роутер: «Клод, …» / выбор / правила / ИИ   │
 │ PCM5102A ◄─I2S──┘   │  │                   │◄────────┼─  → агент: Claude │ Qwen │ Kimi │ … (+fallback) │
 │   └► TPA3116 ► 🔊   │  └─ WS2812 8×8       │  PCM    │     → инструменты: время, погода, таймер, …      │
 │ ILI9341 + тач ◄─SPI─┘     кнопки, АКБ 3S   │         │  текст → речь (Piper / OpenAI-совместимый)       │
 └────────────────────────────────────────────┘         └──────────────────────────────────────────────────┘
```

## Что умеет

- **Несколько агентов сразу.** Claude (Anthropic API) и любые OpenAI-совместимые серверы: Ollama, vLLM, llama.cpp, LM Studio, а также облачные Moonshot (Kimi), OpenRouter и DeepSeek. Новый агент добавляется несколькими строками в конфиге.
- **Выбор агента:**
  - голосом: «Клод, …», «Спроси Квен …», «Переключись на Кими»;
  - тачем или кнопкой на колонке;
  - правилами по ключевым словам;
  - автоматически: маленькая быстрая модель решает, кому отдать вопрос.
- **Запасные агенты.** Если локальный сервер выключен или молчит, вопрос уходит следующему агенту. Пользователь просто получает ответ.
- **Агенты советуются друг с другом.** Инструмент `ask_agent` позволяет, например, локальному Qwen спросить Claude о сложном.
- **Инструменты агентов:**
  - время и дата;
  - погода (open-meteo, без ключа);
  - таймеры с голосовым напоминанием;
  - громкость;
  - подсветка;
  - смена агента.
- **Быстрый ответ.** Сервер получает ответ модели потоком, режет его на предложения и озвучивает их по мере готовности. Воспроизведение начинается после первого предложения.
- **Экран 320×240:**
  - кто отвечает;
  - распознанный вопрос и ответ;
  - уровень звука, Wi-Fi, батарея и громкость;
  - выбор агента касанием.
- **Подсветка WS2812B 8×8:** эффекты «слушаю / думаю / говорю» в цвете агента и ручное управление голосом («включи радугу»).
- **Работа от аккумулятора 3S** с измерением заряда и уходом в сон при разряде.
- **Веб-панель** (`http://сервер:8080`): агенты и их доступность, колонки, громкость, «сказать вслух», текстовые вопросы, история с задержками по каждому ответу.

## Быстрый старт

Подробно — в [docs/SETUP.md](docs/SETUP.md). Коротко:

**1. Сервер** (компьютер или мини-ПК в той же сети, что и колонка):

```bash
cd server
npm install
cp .env.example .env                       # AUTH_TOKEN, ANTHROPIC_API_KEY…
cp config/config.example.yaml config/config.yaml
npm run check-config                       # кто из агентов доступен
npm start                                  # http://localhost:8080
```

**Речь и локальные модели** — проще всего через Docker:

```bash
docker compose --profile speech --profile local-llm up -d --build
docker compose exec ollama ollama pull qwen3:8b
curl -X POST http://localhost:8000/v1/models/Systran/faster-whisper-medium
```

**Проверка без железа:**

```bash
npm run simulate -- --text "Квен, который час?"
```

**2. Прошивка:**

```bash
cd firmware
cp include/secrets.example.h include/secrets.h   # Wi-Fi и AUTH_TOKEN
pio run -t upload && pio device monitor
```

При первом включении колонка предложит откалибровать тачскрин, затем сама найдёт сервер в сети через mDNS.

## Управление

| Действие | Что происходит |
|---|---|
| **SW1** коротко | Слушает. Конец фразы колонка определяет сама по паузе |
| **SW1** удерживать | Слушает, пока держишь кнопку |
| **SW1** во время ответа | Перебить и спросить заново |
| **SW2** коротко | Следующий агент: Авто → Claude → Qwen → Kimi → … |
| **SW2** удерживать | Новый разговор (забыть контекст) |
| Касание центра экрана | Говорить / закончить фразу |
| Касание агента внизу | Выбрать агента |
| «−» / «+» внизу справа | Громкость |
| SW2 при включении | Перекалибровать тачскрин |

**Голосовые команды:**

- «Клод, …», «Спроси Квен …» — задать вопрос конкретному агенту;
- «Переключись на Кими», «Переключись на авто» — сменить агента;
- «Новый разговор», «Забудь всё» — сбросить контекст;
- «Поставь таймер на 5 минут», «Сделай потише», «Включи радугу», «Какая погода?» — команды для инструментов агентов.
