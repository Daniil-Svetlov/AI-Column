# Прошивка AI-Column (ESP32-S3)

**Плата:** ESP32-S3-DevKitC-1 **N16R8** — 16 МБ Flash, 8 МБ Octal PSRAM. Проект на PlatformIO с Arduino-ESP32 2.0.17.

## Сборка и прошивка

```bash
cp include/secrets.example.h include/secrets.h   # Wi-Fi, адрес сервера, токен
pio run                     # сборка (~2,5 МБ, раздел приложения 6,25 МБ)
pio run -t upload           # кабель в порт «UART»/«COM»
pio device monitor          # лог на 115200
pio test -e native          # тесты логики (dsp.h, ring_buffer.h) на компьютере
```

**Библиотеки** PlatformIO ставит сам:

- LovyanGFX — экран и тач;
- arduinoWebSockets;
- ArduinoJson 7;
- Adafruit NeoPixel.

## Файлы

| Файл | Что внутри |
|---|---|
| `include/config.h` | все пины и настройки: звук, детектор речи, подсветка, батарея |
| `include/secrets.h` | Wi-Fi, `SERVER_HOST`/`SERVER_PORT`, `DEVICE_TOKEN` (не в git) |
| `src/main.cpp` | состояния колонки, кнопки, тач, обработка событий сервера |
| `src/audio.cpp` | I2S: микрофоны INMP441 и ЦАП PCM5102A, кольцевые буферы в PSRAM |
| `src/api.cpp` | Wi-Fi, mDNS-поиск сервера, WebSocket |
| `src/display.cpp` | интерфейс 320×240, кириллица, калибровка тача |
| `src/leds.cpp` | эффекты матрицы WS2812B |
| `src/battery.cpp` | напряжение и заряд АКБ 3S |
| `include/dsp.h` | преобразование звука, детектор речи, громкость, проценты батареи — без Arduino |
| `include/ring_buffer.h` | кольцевой буфер для обмена между задачами |

## Индикация

| Подсветка | Экран | Значит |
|---|---|---|
| медленно «дышит» цветом агента | «Нажми и говори» / последний ответ | ждёт |
| круг растёт от голоса | «Слушаю…» | слушает |
| бегущая точка по краю | «… думает» | сервер распознаёт и ждёт ответ модели |
| пульсирует в такт речи | текст ответа + эквалайзер | говорит |
| красная точка в центре мигает | «Нет связи» | нет Wi-Fi или сервера |
| оранжевые вспышки | плашка с текстом | таймер или сообщение из панели |
| красные вспышки | красная плашка | ошибка |

Цвет зависит от агента: Claude — оранжевый, Qwen — фиолетовый, Kimi — синий. Цвета задаются в конфиге сервера.

## Частые настройки `config.h`

| Параметр | По умолчанию | Когда менять |
|---|---|---|
| `MIC_SHIFT` | 13 | меньше — громче микрофоны (12 = +6 дБ) |
| `MIC_CHANNELS` | 0 | 1 или 2 — работать с одним микрофоном |
| `VAD_END_SILENCE_MS` | 900 | колонка обрывает тебя — увеличь; долго ждёт — уменьши |
| `VOLUME_MAX_GAIN_DB` | −16 | на 100% тихо — подними до −12 (не выше −6) |
| `LED_MAX_BRIGHTNESS` | 48 | ярче или тусклее подсветка (матрица ест до 3,8 А на полной!) |
| `LED_SERPENTINE` | 0 | 1 — если строки матрицы идут «змейкой» |
