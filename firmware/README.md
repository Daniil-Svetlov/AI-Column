# Прошивка AI-Column (ESP32-S3, Rust)

**Плата:** ESP32-S3-DevKitC-1 **N16R8**: 16 МБ Flash, 8 МБ Octal PSRAM. Прошивка на Rust поверх ESP-IDF 5.5 (`esp-idf-svc`, std).

| Папка | Что внутри |
|---|---|
| `core/` | вся логика без железа: состояния колонки, детектор речи, обработка звука, интерфейс (embedded-graphics), эффекты подсветки, mDNS, калибровка тача. Тесты: `cargo test` на ПК |
| `esp/` | драйверы платы (I2S, SPI-экран и тач, RMT-светодиоды, АЦП, NVS, Wi-Fi + WebSocket) и `main.rs`. `src/bin/hwtest.rs` — проверка железа |

## Сборка и прошивка

Один раз поставить тулчейн:

```bash
cargo install espup espflash ldproxy
espup install
```

Дальше:

```bash
. ~/export-esp.sh                         # в каждом новом терминале
cd firmware/esp
cp cfg.example.toml cfg.toml              # Wi-Fi, адрес сервера, токен (не в git)
cargo run --release --bin hwtest          # проверка железа без сервера
cargo run --release --bin cowsay          # корова на экране (cowsay)
cargo run --release                       # прошивка колонки + лог (115200)
```

Кабель — в порт «UART»/«COM». Первая сборка скачивает ESP-IDF в `esp/.embuild` (~15 минут). Образ ≈1,4 МБ, раздел приложения — 6 МБ (`esp/partitions.csv`).

Тесты логики на компьютере:

```bash
cd firmware/core && cargo test
```

## Проверка железа (`hwtest`)

| На экране | Как проверить |
|---|---|
| **Кнопки** SW1/SW2 | плашка зеленеет при нажатии, растёт счётчик |
| **Микрофоны** Mic A/Mic B | столбики уровня в дБ: тишина ≈ −70…−60, голос рядом ≈ −30…−20. «нет сигнала» — микрофон не отвечает (SD, питание, L/R) |
| **Экран** | надпись читается слева направо, полосы совпадают с подписями. Если красный и синий перепутаны — `ColorOrder::Rgb` в `esp/src/display.rs`; если зеркально — убери `flip_horizontal()` |
| **Тач** | коснись нижней части экрана — там появится точка, рядом координаты и сырые значения. До калибровки точка может стоять не там — это нормально, калибровка в основной прошивке |

Всё то же каждую секунду пишется в лог.

## Настройки (`core/src/config.rs`)

| Параметр | По умолчанию | Когда менять |
|---|---|---|
| `MIC_SHIFT` | 13 | меньше — громче микрофоны (12 = +6 дБ) |
| `MIC_CHANNELS` | 0 | 1 или 2 — работать с одним микрофоном |
| `VAD_END_SILENCE_MS` | 900 | колонка обрывает тебя — увеличь; долго ждёт — уменьши |
| `VOLUME_MAX_GAIN_DB` | −16 | на 100% тихо — подними до −12 (не выше −6) |
| `LED_MAX_BRIGHTNESS` | 48 | ярче или тусклее подсветка (матрица ест до 3,8 А на полной!) |
| `LED_SERPENTINE` | false | true — если строки матрицы идут «змейкой» |

Wi-Fi, сервер и токен — в `esp/cfg.toml`. `server_host` пустой — колонка ищет сервер по mDNS (`_aicolumn._tcp`).

**Отличие от прежней C++-версии:** подключение к серверу только по `ws://` (в локальной сети). `wss://` (TLS) пока не поддерживается: для сервера в интернете поставь его за VPN или туннель.

## Индикация

| Подсветка | Экран | Значит |
|---|---|---|
| медленно «дышит» цветом агента | «Нажми и говори» / последний ответ | ждёт |
| круг растёт от голоса | «Слушаю…» | слушает |
| бегущая точка по краю | «… думает» | сервер распознаёт и ждёт ответ модели |
| пульсирует в такт речи | текст ответа + эквалайзер | говорит |
| красная точка в центре мигает | «Нет связи» | нет Wi-Fi или сервера |
| оранжевые вспышки | плашка с текстом | таймер или сообщение из панели |
| красные вспышки | красная плашка | ошибка |

Цвет зависит от агента: Claude — оранжевый, Qwen — фиолетовый, Kimi — синий. Цвета задаются в конфиге сервера.
